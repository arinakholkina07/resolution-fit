# Разрешение под экран (тема 29)
> **Docker-образ опубликован в Container Registry этого проекта** - его можно
> скачать и запустить:
>
> ```
> docker pull registry.miem.hse.ru/kg26-27/arvikholkina
> docker run --rm -p 8000:8000 registry.miem.hse.ru/kg26-27/arvikholkina
> ```
>
> Приложение откроется на http://localhost:8000

Веб-приложение, которое автоматически приводит набор изображений произвольного
разрешения к единому экранному формату **1920×1080**, аккуратно заполняет пустые
поля кадра, выполняет веб-оптимизацию и отбраковывает слишком мелкие исходники.

## Описание программы

Программа получает на вход изображения (папку или отдельные файлы) и для каждого:

1. **Вписывает** изображение в кадр 1920×1080 **с сохранением пропорций**
2. **Заполняет пустые поля** кадра (полосы сверху/снизу или по бокам) одним из
   способов:
   - **Размытие исходника** растянутая и размытая копия кадра (по умолчанию)
   - **Сплошной цвет** задаётся пользователем
   - **Градиент** между двумя цветами
   - **Зеркальное отражение** отражение краёв исходника в поля
3. Выполняет **веб-оптимизацию**: сохраняет результат в **WebP** (по умолчанию)
   или **JPEG** с регулируемым качеством, включает прогрессивную развёртку для
   JPEG и максимальный режим сжатия для WebP
4. Выполняет **отбраковку**: если для укладки в 1920×1080 требуется увеличение
   исходника в **≥ порог раз** (по умолчанию **2.0**), файл помечается как
   «отбракован» и **не конвертируется**
5. Складывает результаты в отдельную папку вместе со **сводным отчётом**
   (`report.html`, `report.csv`, `report.json`): какие файлы преобразованы, какие
   отбракованы и почему, насколько уменьшился размер

## Системные требования

**Для запуска (рекомендуемый способ - Docker):**

- Docker (Engine 20.10+), опционально Docker Compose
- ~200 МБ под образ, порт `8000` свободен
- Любая ОС с Docker (Linux/Windows/macOS)

**Для запуска без Docker:**

- Python 3.11+ и зависимости из `requirements.txt`

**Клиент:** современный браузер

## Запуск и загрузка данных

### Запуск через Docker

```bash
docker build -t resolution-fit .
docker run --rm -p 8000:8000 resolution-fit
```

Либо одной командой через Docker Compose:

```bash
docker compose up --build
```

Затем откройте в браузере: **http://localhost:8000**

### Запуск без Docker (для разработки)

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### Порядок работы

1. Загрузить изображения: кнопки **«Файлы»** или **«Папка»**, перетаскивание в
   область загрузки, либо кнопка **«Тестовый датасет»** (в образ встроены 6
   тестовых изображений)
2. Задать настройки: способ заполнения краёв, порог отбраковки, формат и
   качество веб-оптимизации, предпросмотр «до / после» обновляется сразу
3. Нажать **«Обработать все изображения»** - появятся сводка и таблица
   результатов
4. **«Скачать результат (zip)»** - архив с оптимизированными изображениями и
   отчётом, **«Открыть отчёт»** - HTML-отчёт в браузере

## Задействованные инструменты

| Инструмент | Назначение |
|---|---|
| Python 3.11 | язык реализации |
| FastAPI | веб-фреймворк (REST API и отдача интерфейса) |
| Uvicorn | ASGI-сервер |
| Pillow (PIL) | обработка изображений: масштабирование (Lanczos), размытие, градиент, зеркало, сохранение в WebP/JPEG |
| python-multipart | приём загружаемых файлов |
| HTML, CSS, JavaScript | веб-интерфейс (без внешних JS-фреймворков) |
| Docker, GitLab CI | контейнеризация, сборка и публикация образа |

Точные версии зафиксированы в `requirements.txt`


## Использованные генеративные инструменты

При выполнении работы применялась ИИ-генерация:
